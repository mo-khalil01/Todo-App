# Todo App — React Native + GraphQL + Neo4j

Projet réalisé par **Aya Jaber** et **Khalil Mohammad** dans le cadre du cours  
**"Programmation d’applications client"** de la **troisième année de Licence Informatique** à l’Université de Caen.


Une application mobile de gestion de tâches réalisée en **React Native**, utilisant un **backend GraphQL** connecté à une base **Neo4j**.
---

## 🚀 Fonctionnalités

- ✔️ Inscription , Connexion et Suppression : Permet à l'utilisateur de créer un compte , de se connecter et de supprimer son compte
- ✔️ Ajouter une tâche  
- ✔️ Supprimer une tâche  
- ✔️ Marquer une tâche comme faite / non faite    
- ✔️ Persistance des données via API GraphQL  
- ✔️ Authentification JWT  
- ✔️ Synchronisation avec Neo4j  
- ✔️ Interface simple et intuitive en React Native  

---

## 🛠️ Stack technique

### **Frontend**
- React Native  
- React Navigation  
- Hooks React (useState, useEffect)  
- FlatList  

### **Backend**
- GraphQL  
- Apollo Server  
- Neo4j  
- Authentification via Bearer Token
